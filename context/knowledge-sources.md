# Knowledge Sources

The agent's operating patterns were informed by these public repositories:

- `coreyhaines31/marketingskills`: marketing skill taxonomy, product-marketing foundation, CRO, copy, SEO, paid media, analytics, experimentation, social, lifecycle, and revops patterns.
- `hyperfx-ai/marketing-skills`: channel execution, skill composition, research, creative production, measurement, and approval-before-action patterns.
- `hculap/awesome-ai-gtm`: end-to-end GTM lifecycle from strategy and attraction through conversion, closing, retention, experimentation, governance, and orchestration.

This project uses adapted workflows and original Sun Stoppers context. It does not depend on those repositories at runtime.

## Prompt Library Sources

Additional prompt-library patterns have been adapted into `skills/prompt-library-marketing.md` from:

- https://github.com/LucasDitchun/Prompt-Hub
- https://github.com/gvishweshwar/marketing-prompts
- https://github.com/xixu-me/prompt-library/blob/main/writing/marketing-copy-creator.md

Use these as inspiration for structured marketing outputs, not as text to copy verbatim. The agent should translate prompt-library patterns into business-specific strategy, copy, offers, campaigns, hooks, and tests.
