# Brand Scaling Funnel

Use this workflow for Sun Stoppers:

1. Clarify the local offer, service area, proof assets, and capacity.
2. Build awareness with proof-led short-form content.
3. Route every piece to one free-quote action.
4. Respond quickly with vehicle, priority, and timing questions.
5. Recommend the next step and book the install.
6. Follow up with reminders and a post-install review request.
7. Measure leads, response time, quote rate, bookings, show rate, and reviews.

Start with the smallest test that can produce learning in seven days. Do not claim performance before data exists.
